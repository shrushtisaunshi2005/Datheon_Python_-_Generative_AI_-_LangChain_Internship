# Datheon – Python, Generative AI & LangChain Internship

## 🚀 Project Overview

This repository contains the projects and practical assignments completed as part of the **Python, Generative AI & LangChain Internship at Datheon**.

The internship provided hands-on experience in Python programming, Large Language Models (LLMs), Generative AI, LangChain, Retrieval-Augmented Generation (RAG), AI agents, and interactive chatbot development.

The repository includes four tasks demonstrating the development of practical AI-powered applications.

## 🎯 Internship Objectives

- Understand Python programming and Generative AI concepts.
- Learn how to work with Large Language Models (LLMs).
- Explore structured prompt engineering using LLMs.
- Develop document-based question-answering systems using RAG.
- Build autonomous AI agents with multiple tools.
- Create interactive AI chatbots using Streamlit.
- Gain practical experience in developing AI applications.

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.10 or later
- Visual Studio Code
- Git
- Google Gemini API key

### Step 1: Clone the Repository

```bash
git clone https://github.com/shrushtisaunshi2005/Datheon_Python_-_Generative_AI_-_LangChain_Internship.git
```

### Step 2: Navigate to the Project

```bash
cd Datheon_Python_-_Generative_AI_-_LangChain_Internship
```

### Step 3: Open the Required Task Folder

Navigate to the individual task folder you want to execute.

### Step 4: Install Dependencies

Refer to the `requirements.txt` file inside the selected task folder.

```bash
pip install -r requirements.txt
```

### Step 5: Configure API Key

Create a `.env` file inside the relevant project folder and add your Gemini API key:

```env
GEMINI_API_KEY=your_api_key_here
```

**Important:** Never upload your actual API key or `.env` file to GitHub.

### Step 6: Run the Application

Refer to the individual task README for its specific execution command.

For Task 4, run:

```bash
streamlit run app.py
```
